# Bluestock Mutual Fund Analytics Capstone

## Overview

This project is an end-to-end Mutual Fund Analytics Platform developed as part of the Bluestock Fintech Data Analyst Internship.

The platform performs:

* Data ingestion from multiple mutual fund datasets
* Live NAV data extraction from mfapi.in
* Data cleaning and validation
* SQLite database creation
* Exploratory Data Analysis
* Performance and risk analytics
* Interactive Power BI dashboard development
* Final reporting and presentation

## Technologies Used

* Python

* SQLAlchemy
* SQLite
* Matplotlib
