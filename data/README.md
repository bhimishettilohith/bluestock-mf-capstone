# Data Folder

This folder contains all datasets used in the Bluestock Mutual Fund Analytics Capstone project.

## Structure

### raw/

Contains the original source datasets before preprocessing.

### processed/

Contains cleaned datasets and analytical outputs generated during the project.

### db/

Contains the SQLite database used for storage and querying.

## Key Files

* clean_nav.csv
* clean_transactions.csv
* fund_master_clean.csv
* fund_scorecard.csv
* var_cvar_report.csv
* optimal_portfolio.csv
* bluestock_mf.db
